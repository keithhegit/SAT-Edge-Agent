# Security Policy

## Supported Scope

This repository contains source code and documents for an intranet-only remote
sensing workbench.

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly:

1. Do **not** open a public issue with exploit details.
2. Contact the maintainer privately through GitHub security reporting or a
   trusted private channel.
3. Provide:
   - affected file or path
   - impact summary
   - reproduction steps if applicable
   - suggested mitigation if known

## Response Expectations

- Acknowledgement target: within 7 days
- Initial triage target: within 14 days

## Disclosure

Please allow maintainers time to investigate and patch the issue before public
disclosure.
