## Release Policy

- FAIR1M/Kaggle images are not included in this repository release.
- The complete internal geographic metadata bundle is not included.
- Public filenames and image checksums are provided only to identify the experimental sample.
- FAIR1M-derived fields retained in redacted output examples remain governed by the source data terms.
- Users must download the data from an authorized source and follow the current source terms.
- If the source license or redistribution terms change, the source terms take precedence over this note.

The public sample manifest and checksum table contain no image pixels and no internal absolute paths. The source dataset should be cited as: X. Sun et al., "FAIR1M: A Benchmark Dataset for Fine-Grained Object Recognition in High-Resolution Remote Sensing Imagery," ISPRS Journal of Photogrammetry and Remote Sensing, vol. 184, pp. 116-130, 2022, doi: 10.1016/j.isprsjprs.2021.12.004.
